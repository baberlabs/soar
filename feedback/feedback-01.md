# Feedback

Date: 2 April 2026, 15:00 - 16:00

Overall, the client liked the design and the content.

Feedback from client:

- Remove the prototypal language. Website should _act_ like a genuine product.
- Change words and sentences that look AI-generated.
- Have a donate section at the bottom.
- Learn > Session: Let each session have its own page. The session should consist of content, then have key facts highlighted, and then a quiz. Inspiration taken from Duolingo and Reasonal. For these sessions, add in imagery as well.
- Create > Share: selected images should show up.
- Create > Share: allow videos, voice recordings and documents as well.
- Reflect: Limit future letters to "one month."
- Reflect: Seal future letters so a user is not able to see them. Unless they break the seal by force.
- Reflect: The vision board should be an actual board called "Moodboard" on which you can stick photos, recipes, places, books, notes, etc.
- Connect: Add in a section about local events & where to find SOAR events in real life.
- Account: Add more personalisation. Photo. Interests. Peers. Make it look professional. Something similar to Substack's account page.

Personal feedback:

- When registering, ask for membership fee. Ask for card details (dummy). A complete real-like flow.
- Add existing (dummy) proposals.
- Call members as "peers." Connect with a peer. Message a peer. Etc.
- Create: see peer's creations.
